> 版本：2026-11-04  
> 原则：**骨架跟现站走，改默认视图与信息层级；不重做整套视觉**  
> 配套方案：[hot_jian_ing_x_assist_plan.md](./hot_jian_ing_x_assist_plan.md)  
> 示意稿目录：`ui-mocks/`（数字与头像为假数据，只看层级）

---

## 1. 设计目标

| 目标 | 做法 |
| --- | --- |
| 10 秒懂定位 | 工具首屏一句话 + 中文效率默认 |
| 先看效率再看绝对涨粉 | 每帖 / 每千曝光视觉权重大于涨粉数 |
| 闭环可抄 | 榜 → 详情：结论 → 代表帖 → 结构 |
| 诚实可点 | 「需核对」等标签可点开短口径 |
| 自用→开门 | 导航预留「资讯 \| 工具」，自用期可书签直达榜 |

**不做**：仪表盘风图表墙、深色炫技、增长 OS 侧栏（发帖/CRM）。

---

## 2. 视觉基调（沿用现站）

| Token | 建议 |
| --- | --- |
| 背景 | 白 / 极浅灰 `#FAFAF9` |
| 文字 | 深灰近黑，次要信息 `#73726E` |
| 强调 | 玫红/酒红系（可对齐站内已有 accent，示意用 `#B4637A`） |
| 涨 | 绿系仅用于 +Δ |
| 标签 | 浅底圆角 pill，需核对用弱警告色（琥珀浅底） |
| 字体 | 现站无衬线即可；大数字可略加重 |
| 密度 | 表格式、留白克制；移动端优先两列完整（账号 + 每千曝光） |

配色不必换成玫瑰朝霞卡片系统；**工具页保持数据站简洁**，和 X 分享卡是两套场景。

## 3. 页面 A · 涨粉榜（工具默认页）

### 3.1 示意

![涨粉榜首屏示意](./ui-mocks/01_growth_board.jpg)

### 3.2 区块说明（自上而下）

| # | 区块 | 作用 | 交互 |
| --- | --- | --- | --- |
| 1 | 顶栏「资讯 \| 工具」 | 开门后心智；自用期可先弱化 | 工具高亮；资讯回精选 |
| 2 | 标题 + 一句定位 | 「中文 AI 圈 · 涨粉是否值得学」 | 旁链「口径说明」 |
| 3 | 筛选条 | 区 / 窗口 / 排序 / 隐藏需核对 | 中文默认；排序默认**每千曝光** |
| 4 | **本周效率信号** | 结论先于表：1 句 + 3 个账号 chip | 点 chip 滚到行或开详情 |
| 5 | 主表 | 决策扫描 | 行点击 → 详情（侧栏或整页） |
| 6 | 侧栏「值得借鉴」 | 当前选中行的短结论 | 无选中时提示点左侧账号 |

### 3.3 表列优先级

| 优先级 | 列 | 视觉 |
| --- | --- | --- |
| P0 | 账号、**每千曝光**、每帖 | 每千曝光列头强调色；数字加粗 |
| P1 | 粉丝、7 日涨粉、帖、标签 | 涨粉绿字即可 |
| P2 | 数据日、基线天数 | 次要灰字；桌面显示 |

**名次**：中文 Tab 内**筛后重排**（不要「隐藏了还显示全站第 23」）。

### 3.4 空态 / 标签

- 需核对、发帖少、本期无发帖：pill，**可点击**弹出 2–4 行口径。  
- 无双快照 / 无曝光：行不参与效率排序，或整表空态说明缺什么。  
- 页脚常驻：`自采快照 · 与 X 实时会有出入`。

## 4. 页面 B · 账号详情（涨粉 → 可抄）

### 4.1 示意

![账号详情示意](./ui-mocks/02_account_detail.jpg)

### 4.2 区块说明

| # | 区块 | 内容 |
| --- | --- | --- |
| 1 | 摘要条 | 头像、类型/主类目、粉丝、7 日 Δ、每帖、每千曝光、标签、**加入对标** |
| 2 | **值得借鉴**（置顶） | 规则生成 3 条；有「需核对」时第一条必须提示先人工核 |
| 3 | 近 7 日代表帖 | 浏览 Top + 互动率补充，最多 10；链到 X |
| 4 | 内容结构 | 题材 / 形式 /（可选）字数段；条形或简单占比即可 |

路径：`涨粉榜` → 行点击 → 本页；对标篮满 2–5 个 →「同量级对标」。

### 4.3 布局建议

- **桌面**：上摘要；下左结论+结构，右代表帖（或结论通栏 + 下分两列）。  
- **窄屏**：摘要 → 结论 → 代表帖 → 结构，单列栈叠。  
- 示意里的左侧「数据工具」导航可选；**MVP 用顶栏 + 面包屑即可**，避免一上来做厚侧栏。

## 5. 其它页（只定原则，本版不另出图）

| 页 | UI 原则 |
| --- | --- |
| 博主画像 | 同表风格；默认排序**中位浏览**；补**粉丝**列；类型筛可用后再强调筛选项 |
| 同量级对标 | 最多 5 列卡片/表；顶上档位（&lt;1 万等）；每列效率数字对齐 |
| 口径说明 | 长文可读；从标签/「？」深链锚点定位 |
| 本周观察 | 开门后；编辑排版优于仪表盘，像简报 |

## 6. 关键流（ASCII）

```
[工具] 涨粉榜（中文 · 每千曝光）
   │
   ├─ 点 chip / 点行 ──► 账号详情
   │                      ├─ 值得借鉴
   │                      ├─ 代表帖 → 外链 X
   │                      └─ 加入对标 ──► 同量级对标（2–5）
   │
   └─ ？/ 需核对 ──► 口径短说明（弹层或锚点）
```

## 7. 与现站的关系

| 保留 | 改 |
| --- | --- |
| 白底表格式、冷静数字站气质 | 默认中文效率，不是英文涨粉数 |
| 诚实方法论文案 | 标签可点；筛后重排 |
| 精选/日报阅读体验 | 不改成工具看板；仅顶栏分流 |
| 采集与字段 | 详情聚合代表帖与结构 |

## 8. 实现优先级（UI）

| 序 | 项 | 备注 |
| --- | --- | --- |
| 1 | 涨粉榜默认与列强调 | 对应示意 01 |
| 2 | 行 → 详情闭环 | 对应示意 02；侧栏或整页二选一，MVP 整页更简单 |
| 3 | 信号条 3 chip | 规则：效率 Top3（非需核对） |
| 4 | 标签弹层 | 复用口径文案 |
| 5 | 顶栏资讯/工具 | 开门前可只做路由，文案后抛光 |
| 6 | 画像/对标视觉对齐 | P1，同组件库 |

## 9. 验收（看图说话）

- [ ] 陌生人只看涨粉榜首屏，能复述定位句  
- [ ] 不看说明也能发现「每千曝光」是主排序  
- [ ] 从榜进详情，不换站点气质，三步内看到值得借鉴与代表帖  
- [ ] 需核对不是装饰，点得开
