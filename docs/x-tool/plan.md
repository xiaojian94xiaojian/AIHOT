# hot.jian.ing · X 辅助工具完善方案

> 版本：2026-11-04（修订：个人工作台优先 → 再对外开放）  
> 定位：**中文 AI 创作者的对标与决策层**（告诉你该盯谁、学哪条帖、别误会哪类涨粉）  
> 阶段：先自用到每天离不开，再开门；功能按个人验收，信息架构按对外预留  
> 不做什么：排程、Auto-DM、自动关注/点赞、完整增长 OS（TweetHunter / SuperX 战场）

---

## 1. 目标与成功标准

### 1.1 产品一句话

面向中文 AI 圈创作者与操盘手：用**自采快照**回答三件事——

1. **谁在涨**（且涨得是否「干净」）  
2. **为什么涨**（内容结构 / 效率，不是粉丝绝对值）  
3. **我能抄什么**（同量级代表帖 + 可执行结论）

### 1.2 非目标（明确砍掉）

| 不做 | 原因 |
| --- | --- |
| 发帖排程 / AI 写稿 / 常青循环 | Typefully、TweetHunter 已极卷 |
| Auto-DM / Autoplug / 批量互动 | 封号与合规风险；与「辅助决策」冲突 |
| 全站泛账号粉丝清洗 | Circleboom 主场；你的池子是 AI 圈 |
| 伪造历史粉丝曲线 | 诚实方法论是护城河，不估不补洞 |

### 1.3 成功标准（分两段）

**A. 个人验收（开门前必须过）**

| 指标 | 目标 |
| --- | --- |
| 晨间决策 | 连续 10 个工作日，打开效率榜后 ≤10 分钟定下「今天盯谁 / 学哪条」 |
| 涨粉 → 代表帖 | 你常看的中文号点进去，≥90% 有近 7 日代表帖 + 类目 |
| 同量级 | &lt;1 万粉视角能找到 ≥5 个可学对象（含效率不差的黑马） |
| 口径信任 | 「需核对」出现时你知道怎么人工核，不误判为可抄 |

**B. 对外开放 beta（有陌生人进来时）**

| 指标 | 目标 |
| --- | --- |
| 首屏可读 | 未读过文档的人 10 秒内明白：中文 AI 圈 · 涨粉值不值得学 |
| 效率榜可解释 | ≤10 秒能指出「本周该盯的 3 个号」 |
| 闭环覆盖 | 效率榜前 20 点击后 ≥80% 有代表帖 + 类目 |
| 类型可用 | 中文头部 100「类型 ≠ 其他」≥90%；主类目非空 ≥80% |
| 口径一致 | 标签与 methodology 无矛盾；需核对保持「建议核对，不是定论」 |

## 3. 站点策略：先自用，再开门（不合站）

### 3.1 原则

当前站点**只有你自己在用**，但目标是 X 辅助做好后**对外开放**。因此：

- **功能优先级**按个人工作台：早上看完能否决策。  
- **信息架构**按对外产品预留：开门时是「打开入口」，不是另起炉灶。  
- **域名**：继续 `hot.jian.ing`，**现阶段不合站、不新开独立域名**。  
- **精选/日报**：保留自用刷热点；不改成仪表盘；对外可作流量入口，但**不抢工具第一屏**。

### 3.2 导航预留（可先做路由，文案后抛光）

```
hot.jian.ing
├── 资讯（精选 / 日报）     ← 现有首页可仍落这里（自用期）
└── 工具                     ← 对外开放后的主入口心智
    ├── 涨粉榜（默认中文效率）
    ├── 博主画像
    ├── 同量级对标
    ├── 本周观察
    └── 口径说明
```

自用期你可以书签直达 `/x-people/growth`；对外 beta 再把「工具」设为外链/顶栏主推，工具默认页 = 中文效率榜。

### 3.3 个人工作台 → 对外开放路径

| 阶段 | 谁用 | 必须交付 | 刻意不做 |
| --- | --- | --- | --- |
| **W0 自用** | 仅你 | P0：中文效率榜 + 涨粉→代表帖；常看账号类型标完 | 品牌包装、SEO、登录、付费、周报订阅 |
| **W1 自用加固** | 仅你 | P1：同量级对标；画像默认中位浏览；你连用约 2 周过「晨间决策」 | 扩大到全站营销 |
| **B0 开门最小包** | 你 + 受邀/公开访客 | 顶栏「资讯 \| 工具」；工具落地效率榜；口径短文常驻；需核对可点开解释 | 登录墙、收费、Chrome 插件、自动化 |
| **B1 有真实反馈后** | 稳定外来用户 | 本周观察页；种子号日粉丝快照；标注扩到 Top300 | 仍不做 TweetHunter 式执行层 |
| **B2 可选分离** | 工具 DAU 明显高于资讯，或要单独计费 | 再评估 `tools.` 子域或独立站 | 未满足条件不拆 |

### 3.5 什么时候才考虑分站

同时满足再议独立子域/站：

1. 工具侧有稳定外来使用（不是偶发打开），且  
2. 资讯与工具的发布/性能互相拖累，或需要单独登录/付费账本。  

未满足前：**一域两入口**，共用采集。

## 5. 功能规格

### 6.1 P0 · 涨粉榜改造

#### 5.1.1 默认视图

| 项 | 规格 |
| --- | --- |
| 默认区 | **中文区**（英文区一键切换） |
| 默认排序 | **每千曝光涨粉**（效率）；次选：每帖涨粉、涨粉数、涨粉率 |
| 默认窗口 | 7 日；可切 30 日 |
| 默认过滤 | 隐藏：官方团队（若类型已标）、`需核对`（可勾选「显示存疑」） |
| 名次 | **筛后重排**（废弃「只隐藏不改名次」对中文 Tab 的行为） |

#### 5.1.2 表头字段

| 列 | 说明 |
| --- | --- |
| # | 筛后名次 + 相对上周箭头 / 新 |
| 账号 | 昵称 @handle · 类型小标签 |
| 粉丝 | 最近快照 |
| 7日涨粉 | 绝对数 + 率（次要） |
| 帖子 | 窗口内原创帖数 |
| **每帖** | 涨粉 / 帖数 |
| **每千曝光** | 涨粉 / (曝光/1000) · **主排序依据** |
| 标签 | 需核对 / 发帖少 / 本期无发帖 |
| 数据日 | 最近快照日 |

#### 5.1.3 效率榜算法（建议写进口径页）

```
窗口 W = 7 或 30 日（按现有折算规则）
ΔF = 最近快照粉丝 − 基线快照粉丝（已折算）
posts = 窗口内原创帖（转发不计，与现口径一致）
impressions = 窗口内帖子曝光之和（采集快照）

每帖效率     = ΔF / max(posts, 1)    // posts=0 时不参与效率排序，打「本期无发帖」
每千曝光效率 = ΔF / max(impressions/1000, 0.001)

排序默认：每千曝光效率 DESC
并列：每帖效率 → |ΔF| → 粉丝数
```

**剔除/降权规则**

| 条件 | 处理 |
| --- | --- |
| 标签含「需核对」 | 默认不进效率榜；「显示存疑」时可进但置底或灰显 |
| 「发帖少」（如 posts &lt; 3） | 可进榜但角标提示，不进「本周观察」自动稿 |
| 「本期无发帖」 | 不参与效率排序 |
| 类型 = 官方团队 | 默认剔除出中文效率榜 |
| MeshyAI 类异常 Δ（如 −18%） | 保留在涨粉数榜尾部；效率榜可过滤 \|Δ率\| 极端值 |

#### 5.1.4 筛选器

- 区：中文 / 英文 / 全部  
- 粉丝门槛：&lt;1千 / 1千–1万 / 1–5万 / 5–20万 / 20万+ / 自定义  
- 类型：开发者创作者 / 研究者 / 媒体分析 / 创始人高管 / 官方 / 其他  
- 开关：显示存疑、仅有效率样本（posts≥3 且有曝光）

### 6.2 P0 · 涨粉 → 代表帖闭环（账号详情）

路由建议：`/x-people/:handle`（已有则增强）

#### 模块 A · 摘要条

- 粉丝、7/30 日 Δ 与率  
- 每帖、每千曝光  
- 类型、主类目  
- 诚实标签  
- 一键「加入对标」

#### 模块 B · 近 7 日代表帖（最多 10）

排序：浏览 DESC；可选「互动率」  
每条展示：发布时间、浏览、赞/转/评（有则）、形式（图/视频/纯文）、题材、链到 X  

**代表帖选取规则**

1. 窗口内原创帖  
2. 取浏览 Top 5 + 互动率 Top 3（去重后最多 10）  
3. 若窗口帖 &lt; 5，全部列出并提示样本不足  

#### 模块 C · 内容结构（7 日或近 30 帖）

- 题材占比（观点 / 产品 / 模型 / tip / …）  
- 形式占比（纯文 / 图 / 视频）  
- 字数段分布  
- 日均发帖  

#### 模块 D · 值得借鉴（规则生成）

模板示例（可配置）：

- 「窗口内题材以 {top_topic} 为主（{pct}%），爆款样本偏 {form}」  
- 「效率：每千曝光 {x}，同粉丝档中位 {y}，高于/低于中位」  
- 「注意：{标签解释}」——若有需核对，结论第一句必须写「涨粉可能含站外/活动因素，先人工核」

## 6. 数据与口径

### 6.1 沿用并产品化现有口径

已有说明必须在 UI 常驻短版：

- 涨粉 = 最近快照 − 基线快照；间隔不一定正好 7 天；折算过的标「基线」天数  
- 样本来自账号自己的帖子（转发不计）  
- 粉丝与 X 实时会有出入  
- 「需核对」≠ 实锤买粉  

### 6.2 新增口径（效率榜）

写入 `/x-people/methodology` 或独立「涨粉口径」锚点：

- 效率指标定义与剔除规则（见 5.1.3）  
- 中文 Tab 名次为筛后重排  
- 代表帖选取规则（见 5.2）

### 6.3 采集侧建议（工程）

| 项 | 建议 |
| --- | --- |
| 快照触发 | 继续「采到帖子时记粉丝」；对效率榜种子号可加**每日一次**轻量粉丝快照，减少「不发帖无点」 |
| 种子池 | 中文 AI 核心名单独立维护；与英文官方池隔离展示 |
| 曝光缺失 | 无曝光的帖不进每千曝光分母；账号级 impressions=0 则不参与效率排序 |
| 异常检测 | \|7日涨粉率\| &gt; 阈值 或 涨粉 ≫ 同期曝光 → 自动「需核对」 |

## 7. 界面与文案原则

1. **先给结论再给表**：榜顶 1 句「本周中文效率信号」+ 3 个 chip 账号。  
2. **数字可扫**：每帖 / 每千曝光用强调色；绝对涨粉次要。  
3. **标签可点**：点「需核对」弹出口径短文，不跳走。  
4. **空态诚实**：样本不足、无双快照、无曝光 → 说明缺什么，不编曲线。  
5. **移动端**：竖屏优先完整看 账号 + 效率两列；其余横滑。
